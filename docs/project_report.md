
# 指数增强基金量化研究系统 — 项目报告

> **Enhanced Index Fund Quantitative Research System**
>


---

## 摘要

本项目构建了一套完整的**指数增强基金量化研究系统**，覆盖基金池构建、净值采集、收益计算、风险指标评估、研究解读自动生成与可视化展示的全流程。系统以四大宽基指数（沪深300、中证500、中证1000、中证全指）的增强基金为研究对象，基于 **Rule-based Research Interpretation Engine（规则驱动的研究解读引擎）**，自动生成包含五核心指标、基金画像（Profile）、研究标签（Tags）和五段研究摘要的完整分析报告。系统部署于 GitHub Actions，实现每个交易日的全自动数据更新与发布。

## 第一章：项目概述

### 1.1 研究目标

指数增强基金的核心价值在于**持续、稳定地创造超越基准指数的超额收益（Alpha）**。本系统旨在回答以下研究问题：

- 哪些指数增强基金真正具有主动管理能力？
- 如何在同类基金中横向比较收益能力、风险控制和风险调整后表现？
- 如何将研究员的分析逻辑抽象为可复现、可解释的规则体系？

### 1.2 研究对象

| 基准指数 | 增强基金数量 | 代表产品示例 |

## 第三章：核心指标计算

### 3.1 区间涨跌幅

采用 App 展示口径（对齐天天基金/支付宝）：

日收益率与累计净值变化的关系：

$$r_t = \frac{NAV_t}{NAV_{t-1}} - 1$$

> **符号说明：**
> - $r_t$：第 $t$ 个交易日的收益率
> - $NAV_t$：第 $t$ 个交易日的基金净值
> - $NAV_{t-1}$：前一个交易日的基金净值

N 日累计收益率：

$$R_{cumulative} = \frac{NAV_{latest}}{NAV_{base}} - 1$$

> **符号说明：**
> - $R_{cumulative}$：区间累计收益率
> - $NAV_{latest}$：区间最新交易日的净值
> - $NAV_{base}$：区间起始日的净值

其中短期（日/周）使用**单位净值（unit_nav）**，中长期（月及以上）使用**复权净值（adj_nav）**以消除分红拆分影响。

### 3.2 超额收益（Excess Return）

超额收益定义为基金收益与 95% 基准指数收益之差（指增基金仓位上限 95%，乘以 0.95 系数还原真实超额能力）：

$$\alpha_t = R_t^{fund} - 0.95 \times R_t^{benchmark}$$

> **符号说明：**
> - $\alpha_t$：第 $t$ 期的超额收益
> - $R_t^{fund}$：基金在第 $t$ 期的收益率（短期用单位净值，中长期用复权净值）
> - $R_t^{benchmark}$：基准指数在同期的收益率（基于价格指数）
> - $0.95$：仓位系数（指数增强基金股票仓位上限为 95%，约 5% 为现金/债券以应对申赎）
>
> **关键约束**：基金收益与基准指数收益必须在**同一交易日**计算。系统在超额计算前执行日期对齐校验，拒绝跨交易日比较。

本系统进一步做**股息修正**，剥离指数分红对超额的贡献：

$$\alpha_t^{pure} = \alpha_t - \left[ (1 + DY)^{years} - 1 \right]$$

> **符号说明：**
> - $\alpha_t^{pure}$：股息修正后的纯 Alpha
> - $DY$：指数股息率（dividend yield），从中证指数公司获取
> - $years$：计算区间对应的年限（如近一年 = 1.0，近六月 = 0.5）修正后的纯 Alpha 更真实地反映基金经理的主动选股能力。

### 3.3 年化收益率（Annual Return）

基于全量复权净值的几何年化：

$$R_{annual} = \left( \frac{NAV_{end}}{NAV_{start}} \right)^{\frac{252}{N}} - 1$$

> **符号说明：**
> - $R_{annual}$：年化收益率
> - $NAV_{end}$：最新交易日的复权净值
> - $NAV_{start}$：历史起始日的复权净值
> - $N$：起始日至最新日之间的交易日总数
> - $252$：A 股市场一年大约的交易天数（年化因子）

### 3.4 年化波动率（Annual Volatility）

先计算日收益率序列：

$$r_t = \frac{NAV_t}{NAV_{t-1}} - 1, \quad t = 1, 2, ..., N$$

> **符号说明：**
> - $r_t$：第 $t$ 个交易日的收益率
> - $N$：交易日总数

日收益率标准差：

$$\sigma_{daily} = \sqrt{ \frac{1}{N-1} \sum_{t=1}^{N} (r_t - \bar{r})^2 }$$

> **符号说明：**
> - $\sigma_{daily}$：日收益率的标准差
> - $\bar{r}$：日收益率的均值，$\bar{r} = \frac{1}{N}\sum_{t=1}^{N} r_t$
> - $N-1$：自由度修正（样本标准差）

年化：

$$\sigma_{annual} = \sigma_{daily} \times \sqrt{252}$$

> **符号说明：**
> - $\sigma_{annual}$：年化波动率
> - $\sqrt{252}$：将日波动率放大到年（假设收益率独立同分布，方差随时间线性累加）

### 3.5 最大回撤（Maximum Drawdown）

定义历史最高净值序列：

$$Peak_t = \max_{1 \leq i \leq t} NAV_i$$

> **符号说明：**
> - $Peak_t$：从第 1 天到第 $t$ 天之间的最高净值
> - $NAV_i$：第 $i$ 个交易日的复权净值

时点回撤：

$$Drawdown_t = \frac{NAV_t - Peak_t}{Peak_t}$$

> **符号说明：**
> - $Drawdown_t$：第 $t$ 天的回撤幅度（负值 = 亏损比例）
> - $NAV_t$：第 $t$ 天当前的净值
> - $Peak_t$：第 $t$ 天之前的历史最高净值

最大回撤：

$$MDD = \min_{1 \leq t \leq N} Drawdown_t$$

> **符号说明：**
> - $MDD$：整个历史区间内回撤的最大值（绝对值最大的负值）
> - 例如 $MDD = -0.15$ 表示历史上最惨的时候净值从最高点下跌了 15%

### 3.6 夏普比率（Sharpe Ratio）

衡量每单位风险所获得的超额回报：

$$Sharpe = \frac{R_{annual} - R_f}{\sigma_{annual}}$$

> **符号说明：**
> - $Sharpe$：夏普比率（越高越好）
> - $R_{annual}$：基金的年化收益率
> - $R_f$：无风险利率，本系统取 $2\%$（近似一年期定存利率）
> - $\sigma_{annual}$：基金的年化波动率
>
> **含义**：如果 Sharpe = 0.8，意味着每承担 1% 的波动风险，获得 0.8% 的超额回报。

### 3.7 卡玛比率（Calmar Ratio）

衡量年化收益与最大回撤的关系：

$$Calmar = \frac{R_{annual}}{|MDD|}$$

> **符号说明：**
> - $Calmar$：卡玛比率（越高越好）
> - $R_{annual}$：基金的年化收益率
> - $|MDD|$：最大回撤的绝对值（取正数）
>
> **含义**：如果 Calmar = 2，意味着每承担 1% 的最大回撤，获得 2% 的年化收益。

### 3.8 超额年化收益（Excess Annual Return）

将日度超额序列以几何方式年化，与 3.3 节基金年化收益率口径一致：

$$\alpha_{annual} = \left( \prod_{t=1}^{N} (1 + \alpha_t) \right)^{\frac{252}{N}} - 1$$

> **符号说明：**
> - $\alpha_{annual}$：超额年化收益（几何年化）
> - $\alpha_t$：第 $t$ 个交易日的超额收益（定义见 3.2 节）
> - $\prod_{t=1}^{N} (1 + \alpha_t)$：日度超额复利累积因子
> - $N$：日度超额序列的交易日总数
> - $252$：年化因子

### 3.9 跟踪误差（Tracking Error）

衡量超额收益的波动性，反映主动管理策略相对于基准的风险敞口：

$$TE = \sigma_{excess} \times \sqrt{252}$$

其中日度超额标准差：

$$\sigma_{excess} = \sqrt{ \frac{1}{N-1} \sum_{t=1}^{N} (\alpha_t - \bar{\alpha}_{daily})^2 }$$

> **符号说明：**
> - $TE$：年化跟踪误差（Tracking Error）
> - $\sigma_{excess}$：日度超额收益的标准差
> - $\alpha_t$：第 $t$ 个交易日的超额收益
> - $\bar{\alpha}_{daily}$：日度超额收益的均值
>
> **含义**：跟踪误差越低，超额收益越稳定，主动管理策略越可控。跟踪误差 < 5% 通常视为低风险增强策略。

### 3.10 信息比率（Information Ratio）

单位主动风险所获取的超额回报，是衡量主动管理能力的黄金标准：

$$IR = \frac{\alpha_{annual}}{TE}$$

> **符号说明：**
> - $IR$：信息比率（Information Ratio）
> - $\alpha_{annual}$：超额年化收益（3.8 节）
> - $TE$：跟踪误差（3.9 节）
>
> **含义**：IR > 1.0 视为优秀（每承担 1% 跟踪误差获得 1% 以上超额），0.5 为及格线。IR = 0 说明超额收益刚好抵消跟踪误差。

### 3.11 超额最大回撤与超额卡玛（Excess MDD & Excess Calmar）

将 3.5 节和 3.7 节的方法应用于日度超额收益的累计序列，而非基金净值序列：

$$Excess\_Cum_t = \sum_{i=1}^{t} \alpha_i$$

然后在 $Excess\_Cum_t$ 序列上分别计算最大回撤（同 3.5 节公式）和卡玛比率（超额年化收益 / |超额最大回撤|，同 3.7 节公式）。物理含义不变，仅输入序列不同，此处不再重复展开。

## 第四章：同类比较与评价体系

> 五核心指标的具体计算公式见第三章。本章聚焦如何在同一 Benchmark 内横向比较基金。

### 4.1 同类排名方法

所有评价均在相同 Benchmark 的增强基金之间完成（Like-for-Like Comparison）。

**大样本模式**：使用百分位排名法。

对于指标 $x$，组内排名（升序，值越大越好）：

$$rank_i = |\{j : x_j \leq x_i\}|$$

> **符号说明：**
> - $rank_i$：基金 $i$ 的组内排名（1 = 最好）
> - $x_i$：基金 $i$ 在该指标上的取值
> - $|\{...\}|$：集合中元素的个数（即有多少只基金的指标值 ≤ $x_i$）

百分位：

$$pct_i = \frac{rank_i}{N_{group}} \times 100\%$$

> **符号说明：**
> - $pct_i$：基金 $i$ 的百分位（越小越靠前，pct=1% 表示同类前 1%）
> - $N_{group}$：同基准下的基金总数

### 4.2 Alpha 三周期评估

| 周期 | 指标 | 用途 |
|------|------|------|
| 近一月 | month_1_alpha | 短期趋势判断 |
| 近六月 | month_6_alpha | 中期持续性评估 |
| 近一年 | year_1_alpha | 长期超额能力 |

趋势判断引入**容忍区间** $\epsilon = 0.5\%$（`TREND_TOLERANCE`），避免微小波动被误判为趋势：

$$\text{趋势} = \begin{cases} \text{改善} & \alpha_{1m} - \alpha_{6m} > \epsilon \;\land\; \alpha_{6m} - \alpha_{1y} > \epsilon \\ \text{回落} & \alpha_{6m} - \alpha_{1m} > \epsilon \;\land\; \alpha_{1y} - \alpha_{6m} > \epsilon \\ \text{平稳} & \text{otherwise} \end{cases}$$

> **符号说明：**
> - $\alpha_{1y}$：近一年超额收益（`year_1_alpha`）
> - $\alpha_{6m}$：近六月超额收益（`month_6_alpha`）
> - $\alpha_{1m}$：近一月超额收益（`month_1_alpha`）
> - $\epsilon$：趋势容忍区间，默认 0.5%，相邻周期 Alpha 差异小于此值视为随机波动
>
> **含义**：只有当相邻周期的 Alpha 变化幅度超过 $\epsilon$ 时，才认定为真正的趋势变化，否则视为平稳。

## 第五章：研究解读引擎

### 5.1 设计哲学（Five Principles）

1. **同类比较原则（Like-for-Like）**：所有评价仅在相同 Benchmark 基金之间完成
2. **超额优先原则（Alpha First）**：Alpha 代表主动管理能力，是评价核心维度
3. **持续性原则（Consistency over Burst）**：持续创造 Alpha 比单次爆发更有价值
4. **风险收益匹配原则（Risk-Adjusted）**：Alpha 必须建立在合理风险水平之上
5. **可解释性原则（Explainability）**：每条结论可追溯至明确数据与规则

### 5.2 五步解读框架

| 步骤 | 维度 | 核心问题 |
|------|------|----------|
| ① Return | 收益能力 | 基金赚了多少钱？有没有跑赢基准？ |
| ② Risk | 风险控制 | 波动多大？最惨亏多少？ |
| ③ Risk-Adjusted | 风险调整收益 | 每单位风险换来多少回报？ |
| ④ Consistency | 超额持续性 | Alpha 是稳定的还是一时运气？ |
| ⑤ Summary | 综合画像 | 这只基金整体是什么画像？ |

### 5.3 基金画像（Profile）分类

画像由规则引擎按优先级依次判定（命中即停止），共六类：

| 优先级 | Profile | 判定条件 | 解释 |
|--------|---------|----------|------|
| 0 | **观察样本** | 成立不足 365 天，或 `year_1_alpha` 缺失 | 数据不足以参与完整评价 |
| 1 | **指数复制型** | 近一年/六月/一月 Alpha 均 ≤ 0 | 三周期均未跑赢基准，未展现主动管理能力 |
| 2 | **稳健增强型** | Alpha 同类前 10%（且 > 0），或三周期 Alpha 全部 > 0；同时波动率不在同类后 30% 且回撤不在同类后 30% | 超额能力明确，波动和回撤均不过度 |
| 3 | **风险收益优化型** | Sharpe 同类前 30%（且 > 0）、Calmar 同类前 30%（且 > 0）、波动率同类前 30%，三者同时满足 | 风险调整后收益优秀——即使超额本身不突出，单位风险回报仍领先 |
| 4 | **高弹性增强型** | 满足以下任一，且波动率在同类后 30% 或回撤在同类后 30%：① Alpha 同类前 10%；② 三周期 Alpha 全部 > 0；③ 年化收益同类前 30% | 进攻能力强，但伴随高波动或大回撤 |
| 5 | **普通增强型** | 上述均不命中；或一年 Alpha 绝对值 < 0.5%（接近中性） | 增强能力不显著，各项指标处于同类中游 |

> **判定逻辑说明：**
> - "同类前 10%" = 百分位 ≤ 10%（`TOP_EXCELLENT = 0.10`）
> - "同类前 30%" = 百分位 ≤ 30%（`TOP_GOOD = 0.30`）
> - "同类后 30%" = 百分位 ≥ 70%（波动率/回撤升序下 = 排名靠后）
> - 风险收益优化型（优先级 3）在稳健增强型（优先级 2）之后判定，因此 Alpha 突出且 Sharpe/Calmar/低波动同时满足的基金优先被归入稳健增强型，不会被风险收益优化型"降级"

### 5.4 研究标签（Tags）体系

标签分两层：

**状态标签（互斥）**：
- `[观察样本]` — 成立不足一年，数据不足以参与完整评价
- `正常` — 可参与完整研究解读

**能力标签（可叠加）**：
- `[持续跑赢]` — 各周期 Alpha 均 > 0
- `[超额突出]` — 信息比率 IR ≥ 1.0（单位主动风险换取 1 单位以上超额收益）
- `[Alpha稳定]` — 三个周期中至少两个 Alpha > 0（胜率法，与持续跑赢互不排斥）
- `[短期改善]` — Alpha 呈逐期加速趋势
- `[近期回落]` — Alpha 呈逐期衰减趋势
- `[高收益]` — 年化收益排名同类前 30%
- `[低波动]` — 年化波动率低于同类 70%
- `[高Sharpe]` — Sharpe Ratio 排名同类前 30%
- `[高Calmar]` — Calmar Ratio 排名同类前 30%
- `[低回撤]` — 最大回撤低于同类 70%

```yaml

  → 验证数据日期 → 部署到 GitHub Pages
  → 发送邮件通知（含数据日期与看板链接）
  
  支持 workflow_dispatch 手动触发，可选"回填全部历史日期"（向量化2分钟完成）
```

> 注：01（基金池构建）仅在白名单 Excel 变动时手动运行，日常 CI 跳过以减少 API 调用和运行时间。

### 6.2 数据存储策略

- **Excel 白名单**（`fund_whitelist.xlsx`）：基金池唯一定义 + 成立日期 + 最新规模，由研究员直接维护
- **基金详情缓存**（`fund_detail_cache.parquet`）：AKShare API 返回的完整基金元数据，67KB，已提交 Git 避免 CI 重复调用
- **净值增量更新**（`02_update_nav.py`）：已有净值则只拉增量，无净值则全量下载
- **Actions Cache**：`data/nav/`、`data/index/`、`data/return/` 跨 Run 复用，每次 run 用唯一 `run_id` key 保存，前缀匹配恢复最近缓存
- **回填加速**：向量化计算，227 只基金 × 5000+ 交易日仅需 2 分钟

## 第七章：项目亮点

1. **Rule-based Research Interpretation**：不使用大模型，将研究员的分析逻辑抽象为可复现、可解释的规则体系。相同数据输入始终得到一致结论。

2. **五核心指标体系**：覆盖收益（Annual Return）、风险（Volatility、Max Drawdown）和风险调整收益（Sharpe、Calmar）三个维度，超越单一指标评价。

3. **Profile + Tags + Summary 三层研究输出**：不采用难以解释的五星评分，而是画像、标签、研究摘要的组合，更贴近内部研究报告的表达方式。

4. **参数与框架分离**：评价哲学（Methodology）固定，参数（Parameters）可根据样本分布校准。

5. **全自动 CI/CD**：每日定时触发 02→06，跳过 01 减少 API 消耗，冷启动缓存命中后 02 仅增量拉取，全程约 10 分钟。

6. **Excel 即真相架构**：基金池、成立日期、规模数据统一存储在 Excel 白名单中，研究员可直接编辑维护。04 和 06 从 Excel 读取元数据，避免 API 数据滞后或不准确的问题。

7. **东方财富直连**：四大指数行情绕过 AKShare，直连东方财富 HTTP API（`push2his.eastmoney.com`），一次 HTTPS 请求全量数据，10 次递增间隔重试，失败自动回落 AKShare 兜底。

8. **日期对齐与几何年化**：超额计算前强制校验基金与指数日期一致（取 ≤ 基金最新日期的指数数据），超额年化收益采用几何均值 `∏(1+α)^(252/N)−1`，与基金年化收益率口径统一。

9. **向量化历史回填**：从 NAV 重建全量历史超额数据，numpy 数组批量计算替代逐日期循环，227 只基金 × 5000+ 交易日在 2 分钟内完成（原 1 小时+）。

10. **三层展示体系**：绩效看板（四 Tab + 走势图弹窗）、研究看板（三子标签 + 超额分析）、研究 Excel（五段摘要），覆盖从快速浏览到深度分析的完整需求。

11. **交互式研究筛选**：研究看板的综合评价页支持按基金画像类型和研究标签进行即时前端过滤，研究标签自动拆分为独立关键词，无需后端查询即可快速定位特定风格的基金群体。

12. **纯 CSS/JS 暗色主题**：HTML 看板采用深色暗色系设计（#0f1923 底色），无第三方 UI 框架依赖，响应式 Flex 布局，排序与过滤逻辑全部前端完成，零服务器成本。
